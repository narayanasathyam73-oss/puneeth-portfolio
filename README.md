# Puneeth Portfolio

Personal developer portfolio for **Thatavarthi Puneeth Kumar** — Computer Science student and Full Stack Developer.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS v4
- Lucide icons
- CSS/IntersectionObserver-based motion

## Run locally

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

## Content

Most portfolio content is centralized in `src/lib/portfolio-data.ts` so links, resume path, photo, projects, skills, experience, certifications, and education can be updated without editing every component.

## Deployment

The project is ready for Vercel, Netlify, Cloudflare Pages, or another static Vite host.
